# Sources

This package is an illustrative example. No religious authority has reviewed or endorsed it.
This file lists the texts it relies on, which of them are bundled, and what may be quoted
from each.

## Looked up on the web, not bundled

### The Catechism of the Catholic Church

- **What it is.** The Church's present statement of its teaching. Its paragraphs are numbered
  from 1 to 2865.
- **Where it is.** The Holy See publishes it in English at
  https://www.vatican.va/archive/ENG0015/_INDEX.HTM
- **Status.** Under copyright (Libreria Editrice Vaticana), so it is not reproduced here.
- **How the package uses it.** The package tells the model to look a point up through web
  search, to prefer the Holy See's own site, and to give the paragraph number and the link.
  Where a host has no web search, the model says so and keeps to the basics.
- **Quoting.** Quote it only from the page itself, with the paragraph number, and never from
  memory as if the wording were exact.

### The Bible

- No translation is bundled. Most modern translations are under copyright.
- The Holy See publishes the New American Bible at
  https://www.vatican.va/archive/ENG0839/_INDEX.HTM
- **Quoting.** Quote Scripture only from a text you can open in the conversation, and name
  the translation.

## Bundled with the package

### The Apostles' Creed

- **Where it is.** `references/apostles-creed.md`
- **Source and status.** The answer to question 12 of the Baltimore Catechism No. 2, approved
  in 1885. Public domain. The file gives the details.
